# 👑 비스트 챌린지 체스

아이를 위한 챌린지 쇼 테마 체스 게임입니다. 파일 하나(`index.html`)로 동작하며 설치할 것이 없습니다.

## 캐릭터
| 캐릭터 | 체스 말 | 움직임 | 잡으면 상금 |
|---|---|---|---|
| 보스 비스트 | 킹 | 모든 방향 1칸 | 꼼짝 못하게 하면 우승! |
| 슈퍼스타 | 퀸 | 가로·세로·대각선 쭉 | $900 |
| 금고 지킴이 | 룩 | 가로·세로 쭉 | $500 |
| 마법사 | 비숍 | 대각선 쭉 | $300 |
| 점프 호스 | 나이트 | L자 점프 | $300 |
| 챌린저 | 폰 | 앞으로 1칸, 잡을 땐 대각선 | $100 |

## 🎨 캐릭터 고르기
- 처음 화면의 **🎨 캐릭터 고르기**에서 킹·퀸·룩·비숍·나이트·폰마다 장난감 캐릭터 44개 중 하나를 골라요 (팀별로 따로)
- 각 말 아래에는 팀 색 받침대, 오른쪽 위에는 어떤 말인지 알려주는 체스 기호(♚♛♜♝♞♟)가 붙어요
- 온라인 대결에서는 각자 고른 "파란 팀(내 캐릭터)" 세트가 상대 화면에도 그대로 보여요
- 캐릭터 그림은 `characters/` 폴더에 있어요. 그림을 추가·삭제하고 `names.json`을 고친 뒤
  `python3 tools/make_chars.py` 를 실행하면 index.html에 반영돼요
- 장난감 사진에서 오려낸 그림이라 가족끼리만 쓰고, 주소를 공개적으로 퍼뜨리지는 마세요

## 💥 잡기 효과 & 🏆 기록
- 상대를 잡으면 잡힌 캐릭터가 찌그러졌다 빙글빙글 날아가고, 체스판이 흔들리며 별·돈이 터지고 "탈락!/KO!" 도장이 찍혀요
  (룩·퀸을 잡으면 더 크게 "빅 탈락!!", "슈퍼 탈락!!!"). 효과음과 휴대폰 진동도 함께
- 게임이 끝나면 자동으로 기록 저장: 승/패/무, 연승, 총 상금, 탈락시킨 캐릭터 수, 컴퓨터 난이도별·온라인 상대별 전적, 최근 게임 30개
- 배지 12종 (첫 승리, 3연승, 어려움 정복, 퀸 사냥꾼, 천만장자 등)
- 기록은 그 기기(브라우저)에 저장돼요. 다른 기기와 공유되지는 않아요

## 기능
- 게임이 시작되면 체스판이 화면을 꽉 채우고, 나머지 기능은 ☰ 메뉴 안에 들어 있어요
- 🤖 컴퓨터랑(쉬움·보통·어려움) / 👫 한 화면에서 둘이 / 🌐 다른 기기랑(온라인 대결)
- 온라인 대결: 방 만들기 → 친구 화면의 방 목록에서 선택(또는 방 번호 4자리 입력) → 바로 시작.
  핑크 팀은 체스판이 뒤집혀 보이고, "한 판 더"를 둘 다 누르면 팀을 바꿔 새 게임. 새로고침해도 이어서 할 수 있어요
- 캐릭터를 누르면 갈 수 있는 곳 표시 + 캐릭터가 말풍선으로 움직이는 법 설명
- 💡 힌트, ↩️ 되돌리기, 📖 캐릭터 도감, 🔊 효과음 켜기/끄기
- 정식 체스 규칙: 캐슬링, 앙파상, 승진(변신 캐릭터 선택), 체크메이트, 스테일메이트
- 우승하면 상금 $1,000,000 + 축하 효과

## 실행 방법

### 1) 개인 PC 서버 (같은 와이파이 기기끼리 온라인 대결)
```bash
cd beast-chess
python3 server.py
```
화면에 나오는 `http://192.168.x.x:8000` 주소로 폰·태블릿에서 접속하세요. (파이썬 3만 있으면 되고 설치할 것 없음)
`index.html`을 더블클릭해서 열면 컴퓨터 대전·2인 모드만 되고 온라인 대결은 안 돼요.

### 2) Google Apps Script 웹앱으로
1. [script.google.com](https://script.google.com) → 새 프로젝트
2. `Code.gs` 내용을 붙여넣기 (온라인 대결 서버 기능 포함)
3. `+` → HTML → 이름을 `index` 로 만들고 `index.html` 내용을 붙여넣기
4. 배포 → 새 배포 → 유형: 웹 앱 → 배포 → 나온 URL을 아이 태블릿 홈 화면에 추가
