# ♟️ K-Chess (케이체스)

도깨비·호랑이·몽달귀신 같은 **한국 전래 동화 캐릭터**가 체스 말이 된 어린이용 체스 게임입니다.
`beast-chess`와는 완전히 따로 관리되는 **플레이 스토어용 버전**이에요.

| 폴더/파일 | 내용 |
|---|---|
| `index.html` | 게임 (브라우저로 바로 열어도 돼요) |
| `characters.js` | 캐릭터 10종 그림 (모두 직접 그린 오리지널 SVG) |
| `fonts/` | 글꼴 (주아체, 검은고딕 — SIL OFL 무료 글꼴) |
| `android/` | 안드로이드 앱 프로젝트 (패키지 `io.github.ramonbae01.kchess`) |
| `privacy.html` | 개인정보처리방침 페이지 |
| `store/` | 스토어용 아이콘·대표 이미지·스크린샷·설명 문구 |

## 기존 게임(beast-chess)과 다른 점
- 온라인 대결 없음, **인터넷 권한 없음** (개인정보 수집 0)
- 장난감 사진·실존 인물 관련 표현 없음 → 오리지널 캐릭터만 사용
- 상금($) 대신 **엽전(냥)**, 팀 이름은 **청 팀 / 홍 팀**
- 기록·설정은 `kc_`로 시작하는 별도 이름으로 저장

## 캐릭터 (기본 배치)
| 말 | 청 팀 | 홍 팀 |
|---|---|---|
| 킹 | 산신령 | 도깨비 대장 |
| 퀸 | 호랑이 | 신선 |
| 룩 | 울산바위 | 울산바위 |
| 비숍 | 몽달귀신 | 몽달귀신 |
| 나이트 | 까치 | 까마귀 |
| 폰 | 뿔이 (꼬마 도깨비) | 방울이 (꼬마 도깨비) |

## 앱 만들기 (자동)
`k-chess/` 아래 파일이 바뀌어 GitHub에 올라가면 **Actions → K-Chess 앱 만들기**가
- 설치해서 시험해 볼 **APK**
- 플레이 스토어에 올릴 **AAB**

를 만들어 Releases(`kchess-v1.0.N`)에 올려요.

### 업로드 키 (스토어용 서명) 설정
저장소 **Settings → Secrets and variables → Actions → New repository secret** 에 4개를 넣어요:
`KC_KEYSTORE_BASE64`, `KC_KEYSTORE_PASSWORD`, `KC_KEY_ALIAS`, `KC_KEY_PASSWORD`
(키가 없으면 테스트용 임시 키로 서명돼요. 그 AAB는 스토어에 올릴 수 없어요.)
