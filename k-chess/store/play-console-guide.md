## 1단계. 개발자 계정 만들기 (하루~며칠)

1. https://play.google.com/console/signup 에 접속해요.
2. 계정 유형은 **개인(Yourself)**을 골라요. 조직 계정은 D-U-N-S 번호가 필요해요.
3. 등록비 **25달러**를 1회 결제해요. 해외 결제가 되는 카드가 필요해요.
4. 개발자 이름(스토어에 공개됨), 연락처 이메일, 전화번호를 입력하고 인증해요.
5. **신분증 인증**: 주민등록증이나 운전면허증, 여권 사진을 올려요. 승인까지 며칠 걸릴 수 있어요.
6. 안내가 나오면 휴대폰에 **Play Console 앱**을 설치해서 기기 인증을 해요.

## 2단계. 앱 만들기

Play Console → **앱 만들기**를 눌러요.
- 앱 이름: `K-Chess 케이체스 - 전래동화 체스`
- 기본 언어: 한국어
- 앱 또는 게임: **게임**
- 무료 또는 유료: **무료** (나중에 유료로 바꿀 수 없어요)
- 정책 동의 체크 → 만들기

## 3단계. 앱 설정 (대시보드의 "앱 설정" 항목들)

대시보드 → **앱 설정 → 작업 보기**에서 하나씩 채워요.

| 항목 | 답변 |
|---|---|
| 개인정보처리방침 | 위 주소 입력 |
| 앱 액세스 권한 | **모든 기능을 특별한 액세스 없이 사용할 수 있음** |
| 광고 | **아니요, 광고가 없음** |
| 콘텐츠 등급 | 설문 시작 → 카테고리 "게임" → 폭력·공포·성적 내용·도박·약물·욕설: 모두 **아니요**, 사용자 간 소통·위치 공유·디지털 구매: **아니요** → 결과 확인 후 적용 (전체이용가 예상) |
| 타겟층 및 콘텐츠 | 대상 연령에서 원하는 범위를 골라요 (예: **6~8세, 9~12세**). 13세 미만을 고르면 **가족 정책**이 적용돼요. "어린이의 관심을 끌 수 있는가" → 예 |
| 뉴스 앱 | 아니요 |
| 데이터 보안 | "데이터를 수집하거나 공유하나요?" → **아니요** (앱에 인터넷 권한이 없음) |
| 광고 ID | **아니요** (광고 ID를 쓰지 않음) |
| 정부 앱 / 금융 기능 / 건강 | 해당 없음 |

가족 정책 체크 사항: K-Chess는 광고·분석 SDK·로그인·채팅이 없어서 해당 요건을 이미 만족해요.

## 4단계. 스토어 등록정보

**성장 → 스토어 등록정보 → 기본 스토어 등록정보**
- 앱 이름, 간단한 설명(80자), 자세한 설명(4000자): `listing-ko.md`에서 복사
- 앱 아이콘: `icon-512.png`
- 그래픽 이미지(대표 이미지): `feature-graphic-1024x500.png`
- 휴대전화 스크린샷: `screenshot-1` ~ `screenshot-5` (2~8장)
- 태블릿 스크린샷: 선택 사항 (없어도 됨)

**스토어 설정**: 카테고리 **게임 → 보드**, 연락처 이메일 입력

## 5단계. 비공개 테스트 (가장 오래 걸려요: 최소 14일)

2023년 11월 13일 이후에 만든 **개인 계정**은 정식 출시 전에
**테스터 12명 이상이 14일 연속으로 참여하는 비공개 테스트**를 해야 해요.

1. **테스트 및 출시 → 테스트 → 비공개 테스트** → 트랙 만들기 (또는 기본 "Alpha" 사용)
2. **국가/지역**: 대한민국 추가
3. **테스터**: 이메일 목록 만들기 → 테스터 **12명 이상**의 Gmail 주소 입력 (여유 있게 15명 이상 추천)
   - Family Link로 관리되는 어린이 계정은 테스터로 참여하지 못할 수 있으니 **어른 계정**으로 받아요
4. **새 버전 만들기**
   - "Play 앱 서명" 안내 → **사용(권장)** 선택
   - App Bundle에 `k-chess.aab` 업로드
   - 출시 노트: 예) `첫 테스트 버전입니다.`
5. **검토 후 출시** → Google 검토 (보통 하루~며칠)
6. 승인되면 **테스터 참여 링크**를 복사해 테스터들에게 보내요
   - 테스터는 링크에서 **"테스터 되기"**를 누르고 Play 스토어에서 앱을 설치해요
   - 14일 동안 **참여를 취소하지 않고** 가끔 앱을 실행해 주면 좋아요
7. 테스트 중 고친 점이 있으면 새 AAB를 올려 업데이트해요 (출시 신청 때 질문에 도움이 돼요)

## 6단계. 프로덕션(정식 출시) 신청

14일이 지나면 대시보드에 **프로덕션 액세스 신청**이 열려요.
- 테스터를 어떻게 모았는지, 받은 의견, 고친 점 등을 묻는 질문에 솔직하게 답해요
  - 예) "가족·지인 15명이 14일간 테스트했고, 메뉴가 화면에 다 안 들어온다는 의견을 받아 한 화면에 맞게 고쳤습니다."
- 검토는 보통 **최대 7일** 정도 걸려요

## 7단계. 정식 출시

1. **테스트 및 출시 → 프로덕션 → 새 버전 만들기**
2. 비공개 테스트의 버전을 **가져오기**하거나 최신 AAB를 업로드
3. 국가/지역: 대한민국 (원하면 더 추가)
4. **검토 후 출시** → 승인되면 스토어에 공개! 🎉

## 업데이트할 때

- `k-chess/`를 고쳐 GitHub에 올리면 새 AAB가 자동으로 만들어지고 버전 번호도 자동으로 올라가요
- Play Console → 프로덕션(또는 테스트 트랙) → 새 버전 만들기 → 새 AAB 업로드 → 출시
